# 🐱 Sirius Cat Assistant (Alpha)

Sirius — інтерактивний браузерний котик із CSS-анімаціями, звуками, адмінпанеллю та експериментальними голосовими командами українською.

**Це демопрототип, а не AI-чатбот.** Повноцінної мовної моделі тут поки немає.

## Можливості

- 😺 Кіт реагує на натискання, рух курсора та Enter / Space
- 🐾 Махає лапкою, анімується, показує репліки, мурчить і нявкає
- 🎨 Перемикає світлу/темну тему, запам'ятовує вибір
- 📏 Змінює масштаб повзунком; адаптивна панель керування
- 🎙️ Підтримує прості голосові команди українською через браузерний Web Speech API (де доступний)
- ♿ Підтримує керування клавіатурою та системне налаштування reduced motion

Приклади команд: **«привіт»**, **«мяу»**, **«мурчи»**, **«помахай лапкою»**, **«зміни тему»**, **«анімація»**.

> Голосове розпізнавання залежить від браузера, системної мови й дозволу на мікрофон, доступного через HTTPS або localhost. Деякі браузери використовують зовнішній сервіс розпізнавання. Якщо функція недоступна, кнопки залишаються працездатними.

## Запуск

Пакети не потрібні. Запусти локальний HTTP-сервер:

~~~bash
git clone https://github.com/darmaskirov/UA_sirius-cat-assistant.git
cd UA_sirius-cat-assistant
python3 -m http.server 8000
~~~

Відкрий http://localhost:8000/.

## Перевірки

Для Node.js 20+:

~~~bash
node --test tests/smoke.test.mjs
~~~

Smoke-тести перевіряють дубльовані HTML ID, відсутні ресурси, синтаксис скриптів головної сторінки та деякі атрибути доступності. Вони не замінюють ручного браузерного тестування.

## Старий експеримент із Vosk

Каталог `webapi_client/` — незавершена експериментальна спроба інтеграції Vosk і зовнішнього endpoint. Для його роботи бракує `model.tar.gz`, `recognizer-processor.js` та серверного API. Новий голосовий режим головної сторінки від нього не залежить.

Кнопка «Керування домом» поки що вимкнена, оскільки функцію не реалізовано.
